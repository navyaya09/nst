# StyleForge AI

## Project Overview
StyleForge AI is an AI-powered neural style transfer system that transforms content images using artistic style references. The platform enables users to generate visually enhanced stylized outputs through deep learning-based image transformation.

## Features
- Neural style transfer
- Content and style image upload
- Adjustable style intensity
- Real-time AI-generated outputs
- Interactive web interface

## Tech Stack
- Python
- PyTorch
- Deep Learning
- Neural Style Transfer
- Streamlit / Web Interface

## How it Works
1. Users upload a content image and a style reference image.
2. The AI model extracts artistic patterns from the style image.
3. Neural style transfer is applied to the content image.
4. The system generates a stylized output image.
